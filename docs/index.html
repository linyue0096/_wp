Tailwind CSS + Tera 模板 + 響應式設計

在地執行方式

# 安裝 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 執行專案
cd 期中/ecommerce
cargo run

# 開啟瀏覽器
# http://localhost:3000

專案結構

  • 期中/ecommerce/
  • ├── Cargo.toml # 依賴設定
  • ├── src/
  • ├── main.rs # 進入點
  • ├── auth.rs # JWT 認證
  • ├── db.rs # 資料庫操作
  • └── models.rs # 資料模型
  • ├── templates/ # Tera 模板
  • └── static/ # 靜態資源
